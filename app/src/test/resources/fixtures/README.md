# Test fixtures

These are concrete JSON examples derived from SHARED API CONTRACT v1 and the real OpenCode v1.18.35 OpenAPI schema at commit 53d1eabb61e21162157817bf677da0a4ad3332e3. They are not captures from a running gateway and are not a mock server. All `oc-*.json` examples were validated against the pinned OpenAPI 3.1 schemas. `manifest.json` records each source/schema. The 204 fixture is intentionally zero bytes. Pagination cursors come from HTTP X-Next-Cursor, not from the JSON body.
